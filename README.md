# ProjectLib (React + TypeScript + Vite)

## Архитектура

<span style='color: red;'>**NB! Раздел в разработке**</span>

### Общая стуктура папок

```
src/
├── app/
├── entities/
├── features/
├── widgets/
├── pages/
├── shared/
│   ├── ui/
│   ├── lib/              # вспомогательные утилиты
│   └── mocks/            # моковые данные
└── tests
```

#### app

Инициализация приложения, провайдеры, роутинг, глобальные стили

#### entities

_"«что это?» — пользователь, статья"_

Сущности

- Модели и логика конкретных бизнес‑объектов с идентичностью и смыслом
- Базовые UI: простые карточки и др.

#### features

_действие, приносящее бизнес‑ценность_

Слой отвечает на вопрос «что пользователь хочет сделать?». Это не просто UI, а законченный пользовательский сценарий с бизнес‑логикой: «поставить лайк», «подписаться».

Ключевое правило: фича может использовать entities и shared, но не должна знать про другие фичи и страницы.

#### pages

Страницы как сборка из entities/features

#### shared

_"«общие примитивы» — кнопка, инпут"_

Правило: shared не зависит ни от чего. Если компоненту нужна логика сущности — это уже не shared.

#### widgets

_"«как это собрано на странице?» - лента, профиль"_

Композиционные блоки, собирающие сущности и фичи в смысловые куски. Это «кирпичики» страниц.

#### tests

Тесты на vitest
